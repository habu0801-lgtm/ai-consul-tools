# kpi-reporter

店舗の週次売上データを自動集計し、サマリーレポートを生成して関係者に自動送信するツール。

## 概要

スタッフがフォーム等で日々の実績（売上・KPI項目）を入力すると、その回答ログをスプレッドシート上に蓄積。週次でトリガーを実行することで、直近1週間分のデータを自動集計し、スタッフ別・項目別のサマリーをメールで送信する。

- 手動での週次集計・レポート作成の手間を解消
- スタッフ別・項目別の内訳を自動算出
- 過去の集計結果はスプレッドシート上に履歴として蓄積され、振り返りに活用できる

## 構成

```
kpi-reporter/
└── kpi_reporter.gs   # Google Apps Script本体
```

## 想定シート構成

| シート名 | 役割 |
|---|---|
| 回答ログ | フォーム等で送信された日々の実績データ（タイムスタンプ・スタッフ名・項目・金額） |
| 週次レポート | 本ツールが出力する週次サマリーの蓄積先（自動作成） |

## セットアップ

1. `kpi_reporter.gs` の内容をGoogle Apps Scriptエディタに貼り付ける
2. ファイル冒頭の `CONFIG` セクションを環境に合わせて編集する
   - `LOG_SHEET_NAME` : 実績データが入っているシート名
   - `REPORT_RECIPIENTS` : レポート送信先のメールアドレス
3. `testWeeklyReport()` を実行し、ログにサマリーが正しく出力されることを確認する
4. 問題なければ `weeklyReport()` を時間主導型トリガーに登録（毎週月曜 9:00 等）
