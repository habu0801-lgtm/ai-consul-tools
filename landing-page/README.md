# landing-page（事例紹介）

飲食店（ジンギスカン専門店）の集客用ランディングページの制作事例です。

> **本ページは事例紹介です。**
> ページ自体は店舗が公開しているものですが、ソースは店舗側の資産のため本リポジトリには含めていません。
> ここに残すのは制作上の判断だけです。

## 案件概要

- **構成**: 単一HTML（447行）＋ 店舗撮影写真14点
- **セクション**: ストーリー → メニュー（部位別）→ ドリンク → 店内 → アクセス → 予約
- **配信**: ビルド不要の静的ページとして配信

## 制作で判断したこと

### ブランドガイドラインがない状態から世界観を組み立てる

指定のカラーやトーンが存在しなかったため、**実店舗で撮影した写真と、公式SNSの実投稿を起点に**世界観を決めました。

炭火・煙・肉の質感が主役になる題材なので、背景を暗く落として写真のコントラストを立てる方向に振っています。
「なんとなくおしゃれ」に寄せるより、**既に発信されている店の空気に合わせる**ほうが、クライアントの確認コストが下がります。

### 掲載情報は、3ソースを突き合わせてから載せる

価格・営業時間・席数といった情報は、**予約サイト・公式サイト・プレスリリースの3つを突き合わせ、
食い違いを潰してから**反映しました。

LPの情報が実店舗と違うと、客が来てから齟齬が起きます。制作側で拾える食い違いは、
入稿前に確認しておくほうが安全です。実際に複数箇所で表記のズレが見つかりました。

### 予約導線を3系統に分ける

来店意欲の温度感は客によって違うので、導線を1本に絞らず3つ用意しました。

| 導線 | 想定する客 |
|---|---|
| ネット予約（予約サイト） | 日程が決まっていて、今すぐ席を押さえたい |
| 電話 | 当日・人数変更など、相談しながら決めたい |
| Instagram | まだ検討段階。雰囲気をもう少し見たい |

ヘッダーに常時「ネット予約」と「電話」を固定し、**スクロール位置に関係なく予約できる**ようにしています。

### ビルドツールを使わない

フレームワークもビルド工程も使わず、HTML＋画像だけの構成にしました。
クライアント側でホスティング先を選ぶ段階だったため、**どこにでも置ける状態**を優先しています。
（Webフォントのみ外部読み込み）

## 使った技術

HTML / CSS（単一ファイル）、静的ホスティング。JavaScriptフレームワーク・ビルドツールは不使用。
