# landing-page（事例紹介）

店舗集客用ランディングページの制作事例です。

> **本ページは事例紹介です。**
> クライアント店舗の実名・住所・導線を含むため、HTML実物は公開していません。

## 案件概要

多店舗展開している音楽ラウンジ業態の店舗向けに、認知獲得用のランディングページを制作。
単一の `index.html`（HTML/CSS のみ、約520行）で完結する構成にしました。

## 進め方で工夫した点

### 公式SNSから世界観を拾う

ブランドガイドラインの提供がなかったため、**公式Instagramの実投稿を参照して世界観を再現**しました。

- アクセントカラーを、実際の店内照明に合わせたネオン系（ピンク×パープル）に調整
- 週末イベントの見せ方を、実際の投稿内容に寄せる

「なんとなくおしゃれ」ではなく、**既に発信されている雰囲気に合わせる**ほうが、
クライアントの確認コストが下がります。

### 決まっていない導線は、暫定で塞がずに繋ぐ

正式な予約URLが未確定だったため、予約導線を**Instagram DM直リンクで暫定的に開通**させました。

LPは「導線が1つでも死んでいると価値がゼロになる」ので、
確定を待って空欄にするより、暫定でも機能する導線を置くほうが良いと判断しています。
正式URLが決まり次第の差し替えを前提に構成してあります。

### 単一ファイル構成にした理由

ビルドツールもフレームワークも使わない単一HTMLにしました。
クライアント側でホスティングを選ぶ段階だったため、**どこにでも置ける状態**を優先しています。

## 使った技術

HTML / CSS（単一ファイル、依存なし）

## 状態

初版完成。デプロイと最終確認、正式な予約URLへの差し替え、他店舗の住所反映が残タスクです。
