# local-transcriber

音声ファイルをMac上で完結して文字起こしするスクリプト。**クラウドに音声を上げずに**、
タイムコード付き／なしの2種類のテキストを書き出します。

faster-whisper（MITライセンス）をCPUで動かすだけの小さなツールですが、
「AIに音声を渡す」ワークフローの土台としてよく使っています。

## なぜ作ったか

音声メモをAIに渡すとき、これまでは要約サービスに頼るしかなく、**原文テキストが手元に残らない**ため
後から検索・引用ができませんでした。加えて、要約には無視できない欠落があることが実測で分かりました。

38分の音声について、要約サービスの出力と原文を突き合わせたところ、
「要約せず全て出力して」と指示しても以下のような情報が落ちていました。

- 通勤が往復4時間、という前提条件の規模感
- 目標金額の根拠として語られた具体的な数字
- 淡々と述べられた事実関係

傾向として、**感情のこもったエピソードは忠実に拾われる一方、淡々と語った事実と、
即答できず飛ばした質問は落ちる**。

→ **事実の網羅性が重要な場面では、要約ではなく原文を渡す。** そのために原文が必要でした。

## 使い方

```bash
python3.11 -m venv whisper-env
./whisper-env/bin/pip install faster-whisper
./whisper-env/bin/python transcribe.py <音声ファイル> [出力先ディレクトリ]
```

初回実行時にモデル（medium）のダウンロードが走ります。

## 出力

同じディレクトリに2ファイルを書き出します。

| ファイル | 用途 |
|---|---|
| `<元ファイル名>.txt` | プレーンテキスト。AIにそのまま渡す用 |
| `<元ファイル名>_timecode.txt` | `[MM:SS]` 付き。該当箇所を聞き直す用 |

## 構成

- モデル: `medium` / int8量子化 / CPU実行
- 言語: 日本語固定（`language="ja"`）
- VADフィルタ有効（無音区間をスキップして高速化）

## 実測性能

**38.4分の音声を50.3分で処理**（Intel Mac・CPU実行）。
GPUなしの実時間比 約1.3倍なので、「席を立っている間に終わる」程度の体感です。
