# shift-scheduler

スタッフの希望休・イベント対応日をもとに、月間シフト案を自動生成するStreamlitアプリ。

## 概要

複数スタッフの希望休・公平性配慮を考慮しながら手作業で行っていたシフト作成（毎回約90分）を、専用UIから条件を入力するだけで下書きを自動生成できる形に置き換える。

- スタッフ管理・希望休入力・イベント日設定を画面上で行い、プロンプトを都度考える必要がない
- ボタン一つで月間シフトの下書きを自動生成
- 勤務回数が少ないスタッフを優先的に割り当てることで、公平性に配慮
- 生成結果はCSVでダウンロード可能

## 構成

```
shift-scheduler/
├── shift_scheduler.py   # Streamlitアプリ本体
└── README.md
```

## セットアップ

```bash
pip install streamlit pandas
streamlit run shift_scheduler.py
```

ブラウザで4つのタブ（①スタッフ管理 → ②希望休入力 → ③イベント日設定 → ④シフト生成）を順に進めることで、月間シフトの下書きを生成できる。
