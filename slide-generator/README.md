# slide-generator

構成メモをJSONで渡すだけで、**ブランドデザインが統一されたPPTXスライド**を自動生成するNode.js製ジェネレーター。

講座資料をゼロからPowerPointで作る手間をなくし、「構成さえ決まればスライドは即完成する」状態にするために作りました。
市民向けAI講座の資料制作で継続運用しています。

## 特徴

- **JSON → PPTX**：構成を書けばデザインは自動。配色・余白・フォントサイズはテンプレート側が持つ
- **7種類のスライドタイプ**に対応（下記）
- **ブランド差し替え可能**：`brand` フィールドで団体名の表記を変更、`""` で非表示（企業向け・コンサル用途に転用可）
- **カスタムアイコン対応**：`customIcons` に画像パスを書くだけで任意のロゴに差し替え
- **フォントサイズ自動計算**：文字量と余白に応じてサイズを調整

## スライドタイプ

| type | 用途 |
|---|---|
| （表紙） | `title` / `subtitle` / `date` / `speaker` を指定すると自動生成 |
| `agenda` | 目次・全体の流れ |
| `section` | セクション区切り（濃色背景） |
| `content` | 箇条書きコンテンツ |
| `two-column` | 2カラム比較 |
| `table` | 表形式 |
| `image` | 画像スライド |
| `summary` | まとめ（濃色背景） |

## 使い方

```bash
npm install
node generator.js sample.json output.pptx
```

`sample.json` が入力フォーマットのサンプルです。これをコピーして中身を書き換えるのが一番早いです。

## ファイル構成

```
slide-generator/
├── generator.js   JSONを読んでPPTXを書き出す本体
├── template.js    デザインシステム（配色・レイアウト・スライドタイプ定義）
├── sample.json    入力フォーマットのサンプル
└── package.json   依存は pptxgenjs のみ
```

デザインを変えたい場合は `template.js` だけを触れば、`generator.js` は変更不要です。

## 運用で分かったこと

講座の回数を重ねるうちに、毎回同じ指摘を繰り返していることに気づき、
**指摘内容をスキル定義側に書き戻して次回から自動反映させる**運用に変えました（例：自己紹介は必ず2枚目、
アイコンは自作SVGより各サービスの純正PNGを優先）。ジェネレーター本体を育てるより、
「入力の作り方」を蓄積したほうが効きました。
