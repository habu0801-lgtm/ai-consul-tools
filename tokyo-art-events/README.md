# tokyo-art-events

東京都内の美術館の展覧会情報を自動収集し、地図付きで一覧できる公開Webサイトです。

🔗 公開URL: https://tokyo-art-events.vercel.app

## できること

- 都内13の美術館の展覧会情報（開催中・開催予定）を毎日自動収集
- Google Mapsで全館の場所を確認、ピンをタップすると開催中の展覧会を表示
- 開催状況（開催中・開催予定・終了間近）でのフィルタ、展覧会名での検索
- 休館中・自動取得非対応の館も、注記付きで正しく案内

## 技術構成

- **フロントエンド**: Next.js（App Router）+ Tailwind CSS
- **データ収集**: Python（BeautifulSoup）による各館サイトのスクレイピング
- **自動更新**: GitHub Actionsで毎日自動実行、差分があれば自動コミット
- **地図**: Google Maps JavaScript API
- **ホスティング**: Vercel
- **アクセス解析**: Vercel Analytics

## この事例で示せること

- 複数の外部サイトから情報を自動収集し、常に最新の状態を保つ仕組み（店舗・イベント情報サイトなどに応用可能）
- 地図・検索・フィルタを備えた情報提供サイトの構築
- 個人開発でも自動化とクラウドサービスを組み合わせれば、運用の手間をかけずに公開サイトを維持できるという実例
