# video-production

Claude Codeの動画編集スキル（`video-use` + HyperFrames）を使った、会話ベースの動画制作・編集システム。

## 概要

従来の動画編集（FFmpeg・After Effects）では、複雑なコマンドやUIを覚える必要があります。このツールスタックでは、**会話ベースで指示するだけ**で、実写合成・カラーグレード・アニメーション・BGM選定が自動的に実現される仕組みです。

## 実例：くらし×AI活用の会 第4回告知動画

- **仕様**: 20秒 / 1080×1920px（縦型・スマホ最適化）

### 実装内容

#### 1. 実写合成
複数シーンの実映像を統合：
- 冒頭：人物インタビュー（自然な照明・背景）
- 中盤：セミナー会場実写（スクリーン映像含む）
- 終盤：告知情報カード

#### 2. カラーグレード
ブランドカラー #00897B（ティール）で統一：
- テキスト・ボタン・アニメーション要素に同色を使用
- 白背景に対するコントラスト最適化
- 動画全体で一貫した色調

#### 3. テキストアニメーション
HyperFrames 24種を活用：
- メッセージ「AIを、自分専用に育てる90分。」の段階的なアニメーション
- シーン間のトランジション（スムーズな切り替え）
- 講座情報カード（日付・時間・講師・価格・CTA）の表示

#### 4. BGM・音声選定
HeyGenと連携した自動選定：
- セミナーの雰囲気に合った背景音楽（BGM）を自動選択
- ナレーション音声の最適化
- 音声とビジュアルのシンクロ

## 技術スタック

| レイヤー | 技術 |
|---------|------|
| **動画編集エンジン** | FFmpeg（バックエンド） |
| **スキル統合** | Claude Code `video-use` スキル |
| **アニメーション** | HyperFrames 24種類 |
| **UI操作** | browser-use（自動スクリーンスクリーピング） |
| **音声・BGM** | HeyGen API（自動音声選定） |

## 成功の鍵

### 1. 会話ベース指示
FFmpegコマンドを覚える必要がなく、「こうしたい」を話すだけで実現。

### 2. スキル統合
`video-use` / `HyperFrames` / `browser-use` の複数スキルを組み合わせることで、単一ツールでは実現不可能な高度な編集が可能に。

### 3. ブランド統一
カラーパレット（ティール）を意識的に統一し、プロフェッショナルな印象を維持。

### 4. クイックターンアラウンド
従来の動画制作（1〜2週間）に対し、このアプローチなら数時間で完成。

## ポートフォリオ価値

このアプローチは、中小企業・個人事業主向けのAIコンサルティングにおいて以下の価値を示します：

- **効率化実績**：動画制作時間を 90% 削減
- **スキル複合化**：複数 Claude Code スキルの組み合わせによる高度な自動化
- **外部連携**：HeyGen等の外部 API をシームレスに統合

今後のセミナー告知・マーケティング自動化の提案時に、この実績を活用できます。
